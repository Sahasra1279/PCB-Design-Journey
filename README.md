# Basic LED PCB

My first PCB design created using KiCad as part of my PCB design learning journey.

## Overview

A simple LED circuit consisting of an LED, a 1 kΩ current-limiting resistor, VCC, GND, and two test points.

## Components

- LED
- 1 kΩ resistor
- 2 test points

## What I Learned

- Schematic capture
- Component and footprint selection
- PCB layout
- Routing
- Test point placement
- Design Rule Check (DRC)

## Software

- KiCad

## Project Status

Completed as part of a PCB design workshop.
